# Пелетен Център Стара Загора — нов сайт

Изцяло нова визия на [peletencentar.com](https://peletencentar.com), изградена от нулата.

## Какво съдържа

- `index.html` — целият сайт в един самостоятелен файл: стилове, шрифтове (Sofia Sans, вграден за кирилица) и скриптове са инлайн. Няма външни зависимости — работи офлайн и на всякакъв хостинг.

## Секции

1. **Начало** — заглавие с анимирани искри и етикет с актуалните цени на пелетите
2. **Пелети** — Разлог, DEMET Gold Premium, TRON, PJ'S Eco с характеристики и цени
3. **Камини** — сухи (FIRE PLUS, EASY, Petit), с въздуховод (ICP 13C/15C), с водна риза (Insert Idro, Class Idro, HydroTherm, Glass Thermo)
4. **Котли и термопомпи** — BIODOM 27 C5 и Bioblock, димоотводни тръби
5. **Услуги** — доставка до дома, изграждане на отоплителни системи, консултация
6. **Контакти** — телефони, адрес, работно време, Google Maps

## Хостване

Файлът може да се качи директно на всеки хостинг или да се пусне през GitHub Pages
(Settings → Pages → Deploy from branch). Поддържа светла и тъмна тема автоматично
и е напълно адаптивен за телефон, таблет и десктоп.
